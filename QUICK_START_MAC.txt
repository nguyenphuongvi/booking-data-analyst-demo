BOOKING DATA ANALYST LAB — CHẠY NHANH TRÊN MAC

1. Tải booking_data_analyst_qr_demo.zip về Downloads.
2. Mở Terminal ở VS Code và dán cả đoạn sau:

cd ~/Desktop/booking_ai_new
mkdir -p booking_qr_demo
unzip -o ~/Downloads/booking_data_analyst_qr_demo.zip -d booking_qr_demo
source .venv/bin/activate
python -m pip install -r booking_qr_demo/requirements.txt
python -m streamlit run booking_qr_demo/streamlit_app.py --server.port 8503

3. Trên Mac: http://localhost:8503

QUÉT QR TRONG CÙNG WIFI:
- Dừng app bằng Ctrl+C, chạy lại:
python -m streamlit run booking_qr_demo/streamlit_app.py --server.port 8503 --server.address 0.0.0.0
- Mở Terminal khác: ipconfig getifaddr en0
- Nhập http://<IP_MAC_THUC_TE>:8503 vào tab Chia sẻ bằng QR.
- Điện thoại và Mac phải cùng Wi-Fi. localhost KHÔNG chia sẻ được cho điện thoại.

QUÉT QR KHẮP NƠI:
- Deploy repository lên https://share.streamlit.io/.
- Lấy link .streamlit.app thật và dán vào tab Chia sẻ bằng QR.

ĐÂY LÀ BẢN DEMO DÙNG DỮ LIỆU GIẢ LẬP, KHÔNG PHẢI DỮ LIỆU CÔNG TY.
Không thay đổi app.py hay SQLite hiện có của dự án.
